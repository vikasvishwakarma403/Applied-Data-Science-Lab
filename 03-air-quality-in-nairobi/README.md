# 03 Air Quality in Nairobi

Part of WorldQuant University's Applied Data Science Lab.

## Overview

Worked with sensor time-series data tracking particulate matter (PM2.5) levels in Nairobi, Kenya. Extracted data from a MongoDB database, resampled and cleaned the time series, and built ARMA models to forecast future air quality readings.

## Skills and tools

Working with time-series data stored in MongoDB, resampling and handling missing timestamps, autocorrelation and partial autocorrelation analysis (ACF/PACF), ARMA time-series modeling with statsmodels, and walk-forward validation for forecasting.
