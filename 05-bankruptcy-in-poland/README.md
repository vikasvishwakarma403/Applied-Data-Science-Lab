# 05 Bankruptcy in Poland

Part of WorldQuant University's Applied Data Science Lab.

## Overview

Analyzed financial indicators for Polish companies to predict bankruptcy risk. Tackled a heavily imbalanced dataset using resampling techniques and compared ensemble models, balancing precision and recall trade-offs relevant to real-world financial risk decisions.

## Skills and tools

Working with highly imbalanced datasets using over and under-sampling, ensemble models including Random Forest and Gradient Boosting, hyperparameter tuning with grid search and cross-validation, precision-recall trade-off analysis and threshold tuning, and model interpretability with feature importances.
