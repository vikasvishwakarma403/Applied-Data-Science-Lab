# 04 Earthquake Damage in Nepal

Part of WorldQuant University's Applied Data Science Lab.

## Overview

Used structural survey data collected after the 2015 Gorkha earthquake to predict whether a building suffered severe damage. Queried data from a SQL database, dealt with class imbalance, and compared classification models to identify key damage-risk factors.

## Skills and tools

Querying and joining data with SQL, handling imbalanced classification problems, logistic regression and decision tree classifiers, model evaluation with accuracy, confusion matrix, precision and recall, and feature importance and interpretability.
