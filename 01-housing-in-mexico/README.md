# 01 Housing in Mexico

Part of WorldQuant University's Applied Data Science Lab.

## Overview

Explored a dataset of ~21,000 real estate listings across Mexico to investigate whether property price is driven more by size or by location. Cleaned messy real-world data, engineered features from address and geo fields, and built a linear regression model to predict price per square meter.

## Skills and tools

Data wrangling and cleaning with pandas, exploratory data analysis and visualization with Matplotlib, feature engineering from categorical and geographic data, linear regression with scikit-learn, and model evaluation using MAE and R2.
