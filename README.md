# Applied Data Science Lab

## About this program

WorldQuant University's Applied Data Science Lab is a free, project-based program covering eight real-world data science projects. Each project pairs a business problem with a dataset and walks through the full workflow: data wrangling, exploratory analysis, model building, and communicating results. Tools used across the program include Python, pandas, scikit-learn, statsmodels, SQL, MongoDB, and Plotly Dash.

## Projects

01 Housing in Mexico: linear regression on ~21,000 real estate listings to see whether price is driven more by size or location.

02 Housing in Buenos Aires: multivariate regression on apartment prices, handling multicollinearity and categorical encoding.

03 Air Quality in Nairobi: ARMA time-series model forecasting PM2.5 levels from MongoDB sensor data.

04 Earthquake Damage in Nepal: classification model predicting building damage after the 2015 Gorkha earthquake, using SQL and handling class imbalance.

05 Bankruptcy in Poland: ensemble classification (Random Forest, Gradient Boosting) predicting bankruptcy risk on an imbalanced financial dataset.

06 Customer Segmentation in the US: unsupervised learning (PCA and K-Means) segmenting US consumers, with an interactive dashboard.

07 A/B Testing at WorldQuant University: experiment design and chi-square testing on email enrollment data, with a custom ETL pipeline and a three-tier web app.

08 Market Forecasting in India: GARCH volatility model on Indian stock data, served through a custom-built API.
