# 08 Market Forecasting in India

Part of WorldQuant University's Applied Data Science Lab.

## Overview

Building a volatility forecasting model for Indian stock market data. Pulling stock price data via an API, storing and cleaning it in a SQLite database, and building a GARCH time-series model to predict asset volatility, then serving predictions through a custom-built API.

## Skills and tools

API data acquisition, SQLite for data storage, GARCH volatility modeling with the arch library, building and serving a prediction API with FastAPI, and time-series diagnostics for financial data.
