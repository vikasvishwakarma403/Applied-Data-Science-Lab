# 06 Customer Segmentation in the US

Part of WorldQuant University's Applied Data Science Lab.

## Overview

Applied unsupervised learning to survey data on US consumers to segment them into distinct groups for a marketing use case. Reduced dimensionality of the feature space and clustered customers, then built a simple interactive dashboard to explore the resulting segments.

## Skills and tools

Unsupervised learning with K-Means clustering, dimensionality reduction with PCA, choosing cluster count using the elbow method and inertia, interactive visualization and dashboarding with Plotly and Dash, and communicating clustering results to a non-technical audience.
