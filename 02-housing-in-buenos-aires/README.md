# 02 Housing in Buenos Aires

Part of WorldQuant University's Applied Data Science Lab.

## Overview

Built on the Project 1 regression work with a more complex, multi-featured apartment dataset from Buenos Aires. Focused on handling multicollinearity, encoding categorical neighborhood data, and building a more robust multivariate regression pipeline to predict apartment prices.

## Skills and tools

Advanced data cleaning and wrangling with pandas, handling multicollinearity and categorical encoding, building reusable scikit-learn pipelines for imputation, encoding, and scaling, multivariate linear regression, and model interpretation through coefficients and feature importance.
