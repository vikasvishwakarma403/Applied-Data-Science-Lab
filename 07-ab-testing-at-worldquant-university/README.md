# 07 A/B Testing at WorldQuant University

Part of WorldQuant University's Applied Data Science Lab.

## Overview

Designed and analyzed an A/B test to measure whether an email reminder increased program enrollment at WQU. Built a custom Python ETL pipeline to move data from MongoDB into a repeatable analysis workflow, ran a chi-square test for statistical significance, and built a small three-tier interactive web app to report results.

## Skills and tools

Experimental design and A/B testing methodology, custom Python classes for ETL pipelines, MongoDB for data storage and retrieval, chi-square hypothesis testing, and three-tier web app design (data layer, business logic, presentation) with Dash.
